# Problem Set 7 kit · Finance

MGMT 6110 Human-AI Collaboration · Prof. Sungjong Roh, PhD

Everything in this kit is made up for the problem set. No real person is described.

Open the Problem Set 7 step-by-step guide beside this folder. It gives every click, and its agent cards score
each run against the answer key. Each run has its own folder, so that no agent sees another run's work.

| Folder | Run | What it holds |
|---|---|---|
| `files` | Runs 1, 2 and 6 | `claims_oct2026.csv` and `policy.txt` to attach or upload, and `PS7_Finance.xlsx` for Excel |
| `run3` | Run 3, Claude Cowork | the data and the rules, with nothing of mine |
| `run4` | Run 4, the scheduled task | the data and the rules, with nothing of mine |
| `run5` | Run 5, Claude Code | the Week 9 kit: the data, the Agent Skill `expense-check` and the project memory `CLAUDE.md` |
| `run7` | Run 7, your own agent | the data and the rules, with nothing of mine |

Finder hides the `.claude` folder in `run5`, which holds the skill. Press **Command-Shift-.** (full stop) in Finder to
see it.

Keep the guide and any answer key out of these folders, so that no agent can read them.
